Governed Source Contracts

Health, events, snapshots, and explorer authority should stay API and CLI first. These are the validator-native contracts the local planes read from.

/v1/index
Single manifest for route discovery, surface class, and upstream replacement guidance.
 /v1/consensus/status
Consensus status and leader context.
 /v1/proposals/queue/stats
Queue/finality/backpressure counters.
 /v1/proposals/release-flow
Adaptive verified-release stages and governor state.

Recent content and consensus events for operator replay and feed consumers.

Runtime snapshot for automation, dashboards, and support tooling.
